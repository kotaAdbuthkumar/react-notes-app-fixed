# React Notes App

**By: K. Adbuth Kumar**

A simple and beautiful Notes web application built with React.js.  
You can add, delete, and search notes. Notes are saved in the browser's local storage, and the app supports Dark Mode.

---

## Live Demo
https://paydendyer.github.io/react-notes-app  
*(Original demo – you can deploy your own version later)*

---

## Features

- Add new notes
- Delete notes
- Search / filter notes
- Character limit (200) with remaining counter
- Dark Mode toggle
- Notes persist using localStorage
- Fully responsive design (CSS Grid)

---

## Technologies Used

- React.js
- CSS Grid
- localStorage
- nanoid (for unique IDs)
- react-icons

---

## Setup Instructions

1. Clone or download this repository
2. Open the project folder in VS Code
3. Open the terminal in VS Code (`Ctrl + `` `)
4. Install dependencies:

```bash
npm install
```

5. Start the development server:

```bash
npm start
```

6. Open your browser and go to:  
   **http://localhost:3000**

2. Use the search bar to filter notes
3. Click the delete icon to remove a note
4. Click **Toggle Mode** to switch between light and dark theme
